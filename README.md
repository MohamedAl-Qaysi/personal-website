# Mohamed Al-Qaysi — Portfolio

Personal portfolio website for Mohamed Al-Qaysi, a final-semester Software Engineering student at Curtin University with 5+ years of real-world development experience.

**Live site:** [mohamedalqaysi.com](https://mohamedalqaysi.com)

---

## About

A dark navy, AI-themed portfolio showcasing projects, skills, and experience — built from scratch with a focus on clean design and smooth animations.

**Pages:**
- **Home** — hero with typewriter effect, stats, tech stack, project highlights, and about snippet
- **About** — full bio, tech stack grid, and experience timeline
- **Projects** — FiveM Server, SignPal, Streamly, Banking System
- **Contact** — enquiry form with social links

## Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Fonts:** Poppins, Ubuntu, Satisfy (Google Fonts)
- **Animations:** CSS keyframes (orbit, float, fade, typewriter)
- **Deployment:** Vercel

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
